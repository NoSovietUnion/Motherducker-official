# Motherducker Official

This repository contains the official website for the game and project known as Motherducker. It is a lightweight static site built with plain HTML and served as a simple landing page.

## Overview

The project currently includes:

- a homepage at `index.html`
- a browser favicon at `favicon.ico`
- a license reference to the MIT License in `license.md`
- a short project summary in `README.md`

## Project purpose

The site acts as a public-facing landing page for the official Motherducker project, with a simple introduction and a link to the project's published web presence.

## Local preview

Because this is a static HTML project, you can preview it locally by opening `index.html` directly in a browser, or by serving the folder with a small local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
